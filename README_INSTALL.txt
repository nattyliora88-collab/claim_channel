Fund & Claim Channel v1.0.1
ภาพรวมกองทุนและช่องทางการเบิกจ่าย (28 ช่องทางเคลม สปสช. ปีงบประมาณ 2569)
================================================================================

ใช้ทำอะไร
- นับคนไข้ที่มารับบริการแยกตาม 28 ช่องทางเคลมของ สปสช. (43 แฟ้ม / E-Claim / DMIS /
  โปรแกรมระดับชาติ / แพลตฟอร์ม) ตามเงื่อนไขในประกาศ สปสช. ปีงบ 2569
- ทุกครั้งที่มารับบริการอยู่กล่องเดียว (ลำดับชนะ) ผลรวมทุกกล่อง = ฐานส่งเบิกพอดี
- กดลงไปดูความสมบูรณ์ของข้อมูล (Authen / Dx หลัก / DRG) สถานะการเบิก และรายชื่อ HN ได้
- เงื่อนไขของแต่ละช่องและแหล่งอ้างอิง: ดูไฟล์ CONDITIONS.md

ต้องมี
- เว็บเซิร์ฟเวอร์ PHP 8.1 ขึ้นไป (เช่น XAMPP) เปิด extension: pdo_pgsql, pdo_sqlite, curl
- ฐาน HOSxP XE แบบ PostgreSQL (ยังไม่รองรับ MySQL)
- เครื่องเซิร์ฟเวอร์ต่อ https://hosxp.net ได้ (ใช้ตอนเข้าระบบอัตโนมัติจาก HOSxP / Marketplace)

ติดตั้ง
1. แตกไฟล์ไว้ในโฟลเดอร์เว็บ เช่น C:\xampp\htdocs\claim_channel\
2. คัดลอก db_settings.example.php เป็น db_settings.php แล้วแก้ host / dbname / user / password
   (แนะนำผู้ใช้ฐานที่อ่านได้อย่างเดียว แอปไม่เขียนข้อมูลลง HOSxP)
3. โฟลเดอร์ cache\ ต้องเขียนได้ (เก็บยอดสรุปรายวันใน SQLite) และห้ามเปิดให้เข้าจากเว็บ
   (มี cache\.htaccess ให้แล้วสำหรับ Apache)
4. เพิ่มลิงก์ http://<เครื่อง>/claim_channel/ ใน HOSxP Dashboard / Marketplace แล้วเปิดจากการ์ดนั้น
   (ระบบเข้าได้ทางเดียวด้วย session ของ HOSxP เปิดลิงก์ตรงจากเบราว์เซอร์จะเข้าไม่ได้)
5. เข้าเมนู "ตั้งค่าโรงพยาบาล" ตั้งรหัสที่แต่ละโรงพยาบาลใช้ไม่เหมือนกัน
   - รหัส Lab คัดกรองทารกแรกเกิด / TSH (ช่อง DTSH)
   - รหัส Lab HbA1c (ช่อง MOPH_CLAIM)
   - ตึก Home Ward (ช่อง HOMEWARD)
   - คำค้นชื่อยากัญชา (ช่อง DCNB)
   ค่าเริ่มต้นเป็นของโรงพยาบาลหาดใหญ่ ต้องตรวจทุกค่าก่อนใช้งานจริง
6. (แนะนำ) เติมข้อมูลย้อนหลังทั้งปีงบนอกเวลาทำการ ไม่ให้กระทบฐาน HOSxP ช่วงกลางวัน:
     C:\xampp\php\php.exe C:\xampp\htdocs\claim_channel\sync.php 2025-10-01 2026-09-30
   (ประมาณเดือนละ 10-15 วินาที รันซ้ำได้ ดึงเฉพาะวันที่ขาด)

เข้าระบบ
- เข้าได้ทางเดียว: เปิดจาก HOSxP / HOSxP Marketplace (ลิงก์มี ?bms-session-id=...) ระบบตรวจ session กับ
  hosxp.net แล้วเข้าให้อัตโนมัติ ไม่มีช่องกรอกรหัสผ่าน
- ถ้า HOSxP ที่เปิดมาต่อคนละฐานกับ db_settings.php จะไม่ให้เข้า
- เปิดลิงก์ตรง / session หมดอายุ / ออกจากระบบ -> ต้องกลับไปเปิดจาก HOSxP ใหม่
- ไม่ใช้งาน 30 นาที ออกจากระบบอัตโนมัติ

ข้อมูลส่วนบุคคล
- แสดงเฉพาะ HN ไม่แสดงชื่อคนไข้ · ทุกหน้าและทุก API ต้องเข้าระบบก่อน
- อ่านฐาน HOSxP อย่างเดียว · ทุกคำสั่งตั้ง statement_timeout 30 วินาที และกันดึงซ้อนกัน

ข้อจำกัดของเวอร์ชันนี้
- 19 จาก 28 ช่องนับได้ · อีก 9 ช่องรอคำยืนยันเงื่อนไขจากงานประกัน หรือ สปสช. ไม่ได้จ่ายรายครั้ง
- เงื่อนไขทุกช่องเป็นร่างตามประกาศ สปสช. ควรให้งานประกันของโรงพยาบาลตรวจก่อนใช้ตัดสินใจ
- สถานะการเบิกดูได้เฉพาะช่องที่ส่งผ่าน e-Claim / FDH (มีร่องรอยในฐาน)
- ข้อมูลก่อนวันที่ขึ้น HOSxP XE (ข้อมูลย้ายระบบ) อาจไม่มี Fee Schedule ยอดบางช่องจะต่ำกว่าจริง
